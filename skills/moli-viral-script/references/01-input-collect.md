# 01 · 信息收集规则与兜底机制

## 收集顺序

按 SKILL.md 字段表顺序问，不要跳。**5 个字段里必填 4 项**，一次问全，不要挤牙膏式逐条问。

## 追问话术规范

- 一次追问必须列全部缺失项，用口语，不堆术语。
- 示例：「要写出能用的脚本，还差三件事：① 这条视频主要想干嘛——招商、种草还是涨粉？② 受众是谁——潜在代理还是终端买家？③ 具体讲哪个选题？」
- **1 轮上限**。用户答得含糊（"都行""你看着办"）→ 按含糊处理，进兜底，不要追问第二轮。

## 兜底机制（爆款潜质自检）

追问后仍缺字段，从 [05-viral-patterns.md](05-viral-patterns.md) 的「爆款潜质自检清单」自选组合：

| 缺失字段 | 兜底策略 |
|---|---|
| 创作目的 | 按行业默认：招商属性行业（护肤/养生/酒水/本地生活）默认 `recruit`；零售消费品默认 `seeding` |
| 行业 | 用「项目/产品名」反推；推不出则用「中小生意」通用场景 |
| 受众 | 默认「25-45 岁、想搞副业/做生意的人」（招商类）或「25-40 岁女性、注重生活品质」（种草类） |
| 选题 | 选该行业最高频的三个选题之一（见下） |
| 产品/项目 | `product_conversion=null`，走纯种草/涨粉型 |

**兜底产出必须命中自检清单 ≥3 项**，否则重写。命中项少于 3 的脚本没有爆款逻辑，是废稿。

## 各行业高频选题库（兜底用）

- **护肤/美妆**：成分科普、敏感肌避坑、空瓶复盘、平价替代测评
- **养生食品**：场景化饮用（加班/应酬/熬夜）、前后对比、原料溯源
- **酒水**：宴席用酒避坑、收藏价值、品鉴入门、宴请场景
- **母婴**：喂养误区、好物实测、宝宝作息管理
- **本地生活**：门店引流玩法、会员留存、同城获客
- **招商/项目**：回款案例拆解、模式解读、代理政策对比、避坑（识别割韭菜项目）

## 交付时的兜底声明（强制）

兜底生成的脚本，交付时必须附一句：「以下目的/行业/受众/选题为 AI 兜底拟定，可随时替换重生成。」禁止隐去不告。
