# 02 · 脚本类型选型决策树

## 五大型谱

本技能的类型体系按 15 年一线操盘（累计招商回款 10 亿+、30+ 项目实战）的真实场景划分，与通用"内容分类"不同——**按"这条视频在业务链路里干什么"分类**。

| 类型 | 英文枚举 | 业务链路位置 | 判定要素 |
|---|---|---|---|
| 招商型 | `recruit` | 公域引流 → 代理咨询 | 有明确回款/增长结果可展示；受众是"想做生意的人" |
| 种草型 | `seeding` | 公域引流 → C 端成交 | 产品有可视化卖点；受众是终端消费者 |
| IP人设型 | `ip_persona` | 建立信任 → 长期转化 | 主讲人有可背书身份（操盘手/创始人/行业老炮） |
| 活动邀约型 | `event_invite` | 私域激活 → 线下/直播到场 | 有明确时间地点；受众是已入私域的存量 |
| 培训招商型 | `training` | 代理赋能 → 招商转化 | 内容带教学属性；受众是已成交代理或意向代理 |

## 决策树（按顺序判）

```
1. 目的是"招商/招代理/回款"？ → recruit
2. 目的是"卖货/C端成交"？ → seeding
3. 目的是"请人来到场（品鉴会/招商会/直播）"？ → event_invite
4. 目的是"教代理/教客户点什么，顺带转化"？ → training
5. 目的是"立人设/涨粉/长期信任"？ → ip_persona
```

多目的并存时**只选一个主类型**，次要目的揉进中段，禁止一鱼两吃。

## campaign_types 枚举

| 枚举 | 适用类型 |
|---|---|
| `agent_recruit` | recruit / training |
| `c_end_seeding` | seeding |
| `brand_exposure` | 全部 |
| `fan_growth` | ip_persona / seeding |
| `event_drain` | event_invite |
| `training_conversion` | training |

至少选 1 项；主类型决定默认值。

## 中段段数上限

- `training`（培训招商型）：≤7 段——教学内容需要分段递进。
- 其余四型：≤5 段——非教学脚本超过 5 段必出现白开水。

## 各类型的 Hook 差异

| 类型 | Hook 公式 | 真实案例锚点（作者履历） |
|---|---|---|
| recruit | 结果数字 + 身份反差 | "4 个月，一个人，回款 150 万——超过另外三个渠道半年总和" |
| seeding | 场景痛点 + 反转承诺 | "应酬前喝一支，第二天照常开早会" |
| ip_persona | 身份声明 + 反常识观点 | "做了 15 年微商，我劝你别碰这三种品" |
| event_invite | 稀缺名额 + 圈层暗示 | "30 人的场子，来了一半是开厂的朋友" |
| training | 知识点 + 可得性 | "代理分层就三层，多一层都是给自己挖坑" |
