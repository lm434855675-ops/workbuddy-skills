# 04 · 合规规则（质检用）

Step 4 质检逐条扫。命中必改项 → 回 Step 3 重写；命中建议项 → 提示用户自行决定。

## 1. 极限词（必改，自动替换）

最、第一、顶级、绝对、100%、史上、独家、国家级、秒杀（非平台活动语境）、吊打、封神、绝了、无敌、躺赚、稳赚、保本、零风险、无风险。

替换策略：

| 原词 | 替换方向 |
|---|---|
| 最/第一 | 具体名次或事实（"我们团队测过的第三种打法"） |
| 100% | 具体比例（"十个人里七个"） |
| 零风险/保本 | 删除，或改写为"风险点先说清楚" |
| 躺赚/稳赚 | 删除，改写为付出与回报的因果关系 |

## 2. 收益宣称红线（必改）

- 禁止承诺具体回报（"投 5 万三个月回 20 万"）——除非是**已完成的真实案例且带条件**（时间、投入、品类、前提缺一不可）。
- 禁止用个例暗示普遍性（"我朋友做了半年买了车"）——须补一句"结果因人而异"。
- 回款数字必须可溯源：真实案例、可查证。**禁止编造回款截图内容**。

## 3. 价格合规（必改）

出现价格必须同时带规格与条件：「5980 一档含三次复盘」而非「5980」；「县级代理 2 万起，含首批货」而非「2 万做代理」。

## 4. 平台规则（必改）

- 诱导互动表述降权："不转不是中国人"式道德绑架、虚假倒计时（"最后 1 小时"但活动不存在）。
- 医疗/功效宣称按品类红线处理（护肤品禁治疗宣称，养生食品禁疗效宣称）。
- 招商类内容须规避传销特征表述：多级分销、拉人头返利、入门费——涉及代理分润只讲"销售分润"，不讲"拉人头提成"。

## 5. 口语化自然度（建议）

- 单句 ≤15 字，长句拆短。
- 停顿用「...」标，不用标点堆叠。
- 禁书面连接词：此外、因此、综上、然而、换言之。
- 禁广告腔：亲们、家人们、宝宝们、抓紧抢购。

## 质检输出格式

```
【必改】N 处：逐条列 原文 → 改法
【建议】N 处：逐条列 原文 → 建议方向
结论：通过 / 回炉重写
```
