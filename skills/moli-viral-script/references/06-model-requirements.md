# 06 · 模型档位与降级

## 档位要求

| 环节 | 最低档位 | 说明 |
|---|---|---|
| Step 3 结构化生成 | 中档及以上 | 需要同时维护 JSON 结构 + 台词口语化 + 时间轴自洽 |
| Step 4 合规质检 | 中档及以上 | 极限词与收益宣称识别对模型敏感度有要求 |
| 兜底自检 | 中档 | 命中 ≥3 项判定 |

轻量模型可用于：信息收集对话、兜底选题推荐。

## 降级策略

1. **首选降级**：生成与质检拆两轮——先轻模型产稿，中档模型只跑 Step 4 质检。
2. **结构降级**：模型跟不上 JSON 时，允许先产纯文本稿 → 由 agent 手工组装 JSON → 再过 render_script.py 校验。**时间轴与枚举的最终裁判永远是脚本，不是模型。**
3. **兜底降级**：模型输出的台词广告腔重 → 用 04 号文件的替换表走一遍自动改写，再交付。

## 铁律

- 交付前 `render_script.py` 退出码必须是 0。脚本不过，模型再强也不算数。
- 任何情况下不向用户暴露"模型档位不足"作为交付质量差的理由——降级路径走完再交。
