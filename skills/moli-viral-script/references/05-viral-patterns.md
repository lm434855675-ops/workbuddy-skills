# 05 · 爆款潜质自检清单 + 打法模式库

## 爆款潜质自检清单（兜底必过，命中 ≥3 项）

1. **利益点前置**：前 3 秒有具体好处或结果数字，不是铺垫。
2. **结果可视化**：有数字、有对比、有画面感（回款、增长、时间节省）。
3. **身份共鸣**：受众能对号入座（"一个月挣三四万的县城小老板"）。
4. **权威背书**：资质、保单、签约、履历、可查证案例，至少一样。
5. **信息增量**：中段每 15 秒有新东西（知识点/案例/对比/反转）。
6. **行动路径短**：CTA 只有一个动作，一步能完成。
7. **情绪钩子**：有一样在场情绪——好奇、意外、紧迫、认同之一。
8. **系列延展性**：结尾能自然接下一集（"下一篇讲怎么分层」）。

## 打法模式库（作者 15 年操盘实证）

以下打法全部来自真实项目沉淀，写脚本时按类型取用：

### F1 · 回款案例钩子（招商型）

结构：结果数字 → 时间/投入反差 → 过程一句带过 → 方法预告。

实证：酵素项目起盘首月回款 500 万；酱酒项目筹备 3 个月回款 1038 万；农业公司第 4 个月招商首月回款超 150 万、超其他三渠道半年总和。

要点：数字必须带**前提**（品类、周期、团队状态），孤零零的数字不可信也违规。

### F2 · 权威背书法（全类型）

结构：可查证背书 → 与受众的关系 → 你能得到什么。

实证：卫视广告投放 + PICC 千万投保（酵素）；CCTV 战略签约 + PICC 承保（私护）；国内唯一植物干细胞银行 + 南山高新项目（护肤品）；万亩种植基地 + 国家级检测研究院（菊芋）。

要点：背书只陈述事实不夸大；无背书的品用人设背书（15 年操盘履历）替代。

### F3 · 圈层场景法（活动邀约/招商型）

结构：场景画面 → 圈层暗示 → 名额稀缺 → 到场动作。

实证：10-30 人高端品鉴会（宝安壹方城钻卡会员、广发私行客户），单场 20 万订单；招商会单场 300 万回款。

要点：画面要具体到"谁在场、喝什么、聊什么"，虚的"高端聚会"没有转化力。

### F4 · 知识 IP 人设法（IP人设型/培训型）

结构：反常识观点 → 履历背书一句 → 三点干货 → 关注理由。

实证：妇科健康知识 IP 人设 1V1 承接日进线 1500+；代理商学院分层培训（内训课教产品知识、公开课促成交）。

要点：干货必须"拿走就能用"，藏一半的干货留不住人。

### F5 · 前后对比法（种草型）

结构：痛点场景 → 使用前后对比 → 真实感细节 → 转化。

实证：护肤品项目"多位 KOC 在 10 万级无尘车间 0 距离接触植物干细胞"。

要点：对比靠细节不靠形容词；"第二天照常开早会"胜过"效果非常好"。

### F6 · 避坑警示法（涨粉/招商通用）

结构：危险信号 → 三类特征 → 自保动作 → 关注追更。

实证：识别割韭菜招商项目；代理分层过多、政策返利过高的模式风险。

要点：警示类内容天然高完播，但禁止为引流夸大风险恐吓用户。

## 反爆款特征（出现即回炉）

- 开头 3 秒是自我介绍/公司介绍/"slogan 喊麦"。
- 中段连续两段没有新信息。
- CTA 超过一个动作。
- 全文形容词密度 > 名词密度（空）。
- 收益数字无前提。
