# 招商起盘测算器

帮你把"这个盘怎么起"这类诉求，转成**带代理分层、价格体系、返利保本与回款倒推的量化方案**。
本 skill 只做测算与政策结构：**回款倒推 → 分层设计 → 价格体系 → 返利保本 → 冲突检查**。不承诺回款结果。

## 第一步：信息收集

| 字段 | 含义 | 必填 |
|---|---|---|
| 产品 | 品类 + 成本 + 建议零售价 | 必填 |
| 目标 | 回款目标 + 时间窗口 | 必填 |
| 盘子 | 首批招募代理数预期 / 现有渠道基础 | 必填 |
| 约束 | 预算、团队、合规边界（如不得多级） | 选填 |

**最多问一轮，答不上标「待补」+默认假设。**

## 第二步：四步测算（全走脚本，禁止口算）

```bash
# ① 回款倒推：目标 → 所需代理数 → 每层任务
python3 scripts/recruit_calc.py back-solve --target-gmv 10000000 --months 6 \
    --agent-price 20000 --avg-order 15000 --repurchase-months 2

# ② 分层让利与保本：每层的进货价、零售价、毛利空间
python3 scripts/recruit_calc.py tier --tiers "联创,50000,300,1" --tiers "总代,10000,180,5" \
    --tiers "区代,2000,120,20" --retail 299 --cost 60

# ③ 政策叠加冲突：返利+折扣+进货赠送叠加后是否击穿成本
python3 scripts/recruit_calc.py stack --cost 60 --retail 299 --agent-price 120 \
    --volume-rebate 15% --signup-gift 10% --season-discount 8%

# ④ 起盘节奏排期
python3 scripts/recruit_calc.py rhythm --target-agents 500 --weeks 12 --curve logistic
```

## 第三步：政策结构输出（方案固定五件）

1. **代理分层表**：层级/进货价/首批门槛/考核/权益。
2. **价格体系**：零售价/各层进货价/毛利空间表。
3. **返利与激励**：量返/店返/年度返的结构与上限。
4. **保本红线**：每层让利率、叠加后底线。
5. **起盘排期**：预热/首发/放量/维稳四段与每段代理数目标。

## 第四步：合规与风险声明（强制）

方案必须附：① 本测算基于用户输入假设，不构成回款承诺；② 代理体系设计须符合《禁止传销条例》，
层级描述只讲销售分润不讲拉人头提成；③ 涉及食品/化妆品品类的，代理政策不得含疗效宣称。

## 退出码处理

| 脚本 | 码 | 含义 | 处理 |
|---|---|---|---|
| recruit_calc.py | 0 | 成功 | 用输出数字 |
| | 1 | 参数错误 | 检查参数格式（`--tiers` 四段：层级,进货价,零售价,层级数） |
| | 2 | 测算无解 | 如叠加让利 ≥ 毛利、倒推所需代理数为负；改政策参数重跑 |

## 全局硬规则

| 项 | 要求 |
|---|---|
| 让利率红线 | 每层让利率 < 该层毛利率；叠加后总让利 < 零售价-成本的 60% |
| 分层上限 | 代理层级 ≤3 层；多于 3 层合规风险与运营成本双失控 |
| 回款构成 | 回款 = 首批进货 + 复购；方案必须分开算，混算必虚高 |
| 首批门槛 | 与产品价值匹配；门槛定到代理要借钱的程度，起盘即崩 |
| 价格体系 | 各层价差 ≤ 进售价的 40%，防止窜价 |
| 不承诺结果 | 只给结构与测算，禁止"保证回款"表述 |

## 常见反模式：看到就纠正

- **"层级越多动力越强"** → 三层封顶；多层=合规红线+管理失控+价格穿底。
- **"首批门槛定高一点筛选优质代理"** → 门槛超过代理支付能力=起盘即崩；用首批量+复购考核替代高门槛。
- **"返利给高一点代理才肯干"** → 先跑 stack 检查，叠加击穿成本的返利是给自己挖坑。
- **"先招 1000 个代理再说"** → 先算承接与服务能力；服务不了的代理是负资产（退货+口碑）。
- **"对标某品牌的返利政策"** → 只对标结构，数字必须用自己成本结构跑。
- **"回款目标倒推就行"** → 倒推给的是结构不是结果；必须配起盘节奏与每段验证点。
