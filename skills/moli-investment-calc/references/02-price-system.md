# 02 · 价格体系：价差控制与窜价防控

## 价格带结构（四价必齐）

```
零售价 → 基层进货价 → 中层进货价 → 顶层进货价（+ 产品成本）
```

四价的关系用 recruit_calc.py tier 测算，逐层算毛利空间与让利率。

## 价差红线

- 相邻层价差 ≤ 进售价的 40%（经验值）：价差过大，中层有强动力窜价到基层。
- 基层毛利空间 ≥ 零售价的 30%：基层赚不到钱，盘子没有动销终局。
- 顶层让利率 < 顶层毛利率：叠加返利前就要留足安全垫。

## 窜价防控三件套

1. **区域限定**：各层货流区域可追溯（码/系统）。
2. **考核挂钩**：窜价取消返利与晋升资格，写进政策。
3. **价盘统一**：统一零售指导价，划线价必须真实成交过并留存举证。

## 价格调整纪律

- 调价只调未发货部分，已发货的不追溯。
- 降价前先给老代理补偿机制（补货/返利），否则信任崩盘。

## 实证锚点（作者履历）

小熊鉴酒项目：酒款定价体系规整+招商政策制定；酵素项目：产品定价与代理商框架从零构建——
**价盘是招商政策的骨架，骨架歪了，激励设计越猛死得越快**。
