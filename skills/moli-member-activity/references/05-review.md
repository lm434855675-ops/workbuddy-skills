# 05 · 复盘口径：增量核算与分层数据表

## 增量核算（唯一口径）

```
活动增量 GMV = 活动期 GMV − 平日日均 GMV × 活动天数
活动增量利润 = 增量 GMV × 毛利率 − 权益总成本 − 触达成本
ROI = 活动增量利润 / 总投入
```

不扣基线的 GMV 涨幅不作为复盘结论。"涨了 3 倍"可能是基线太低或透支后一周。

## 分层数据表（复盘必出）

| 维度 | 指标 |
|---|---|
| 分层 | 各档位参与率/客单/增量 GMV/权益核销率 |
| 权益 | 各权益领取率/核销率/核销成本 |
| 触达 | 各渠道到达率/打开率/转化归因 |
| 节奏 | 各时段成交分布（验证排期合理性） |

## 复盘三问（决定下一轮）

1. 哪个权益杠杆贡献了主要增量？（下次做深它）
2. 哪个分层响应超预期/不及预期？（调整分层策略）
3. 哪个时段/渠道效率显著高/低？（调整排期与触达顺序）

## 透支检查

- 活动后 7 天日均 GMV 与活动前对比：下滑超过 20% 说明透支了后续需求，下一轮降权益力度。

## 实证锚点（作者履历）

品酒会/招商会/代理旅游等活动的结案结算全链路把控（活动成本控制+结案报告）：
复盘的目的是校准下一轮，不是给上一轮打分。
