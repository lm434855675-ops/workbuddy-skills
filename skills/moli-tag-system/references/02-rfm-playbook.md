# 02 RFM 八分法作战手册

## 切分规则（脚本自动执行）

- **R** = 最近一次购买距今天数，越小越好
- **F** = 周期内购买次数，越大越好
- **M** = 周期内消费金额，越大越好
- 各按**中位数**切高低 → 8 个客群（均值会被大单拉爆，禁用）

## 八客群作战表

| 客群 | R | F | M | 动作 | 资源投入 |
|---|---|---|---|---|---|
| 重要价值 | 高 | 高 | 高 | VIP 权益+新品优先 | 高 |
| 重要保持 | 低 | 高 | 高 | 7 天内定向唤醒券 | 高 |
| 重要发展 | 高 | 低 | 高 | 提频：连带、订阅 | 中 |
| 重要挽留 | 低 | 低 | 高 | 强召回：大额券+电话 | 高 |
| 一般价值 | 高 | 高 | 低 | 满减阶梯提客单 | 中 |
| 一般保持 | 低 | 高 | 低 | 轻触达，不投人工 | 低 |
| 一般发展 | 高 | 低 | 低 | 新客 3 次触达 SOP | 中 |
| 流失 | 低 | 低 | 低 | 不主动投入 | 零 |

## 资源分配铁律

**重要挽留 + 流失 >40% → 本月全部资源投召回，不投拉新。**
挽留成本 ≈ 拉新成本 1/5，老客客单高 30%+。算不过来的账不要赌。

## 分层名单的用法（脚本自动导出 CSV）

1. 按客群筛出名单 → 导入企微/群发工具 → 分层发送
2. 每周重跑，盯**客群迁移**：价值客户跌入挽留 = 最高级别流失预警
3. 召回动作只投「重要挽留」——流失客户等大促自然回流，别烧钱

## 数据口径

- R 的周期 = 该品类平均复购周期的 1.5 倍（烘焙 30 天，家电 365 天，别套同一模板）
- M 只算实付（不含退款）
- 新客不足一个周期的，单独标「新客观察」，不强行分 8 类
