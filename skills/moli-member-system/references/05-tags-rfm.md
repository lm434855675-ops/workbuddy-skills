# 05 标签体系与 RFM 八分法

## 四层标签体系

| 层 | 举例 | 来源 | 更新频率 |
|---|---|---|---|
| 基础 | 性别/城市/渠道来源 | 注册信息 | 静态 |
| 行为 | 最近购买/购买频次/客单区间/品类偏好 | 订单数据 | 每单更新 |
| 偏好 | 价格敏感度/促销型 vs 正价型/内容偏好 | 互动+浏览 | 周更 |
| 生命周期 | 新客/复购/沉睡/流失/唤回 | RFM 计算 | 周跑 |

**原则：先打「会被用的」标签。** 每个标签必须对应一个触达动作（谁用、什么时候用、发什么），没有动作的标签不打——打标和维护都有成本。

## RFM 八分法（脚本 rfm 命令）

- R = 最近一次购买距今天数（越小越好）
- F = 一定周期内购买次数（越大越好）
- M = 一定周期内消费金额（越大越好）
- 各按**中位数**切高低 → 8 个客群

| 客群 | R | F | M | 动作 |
|---|---|---|---|---|
| 重要价值 | 高 | 高 | 高 | VIP 权益，防流失 |
| 重要保持 | 低 | 高 | 高 | 7 天内定向唤醒券 |
| 重要发展 | 高 | 低 | 高 | 提频：连带、订阅 |
| 重要挽留 | 低 | 低 | 高 | 强召回：大额券+电话 |
| 一般价值 | 高 | 高 | 低 | 提客单：满减阶梯 |
| 一般保持 | 低 | 高 | 低 | 轻触达，不投人工 |
| 一般发展 | 高 | 低 | 低 | 新客 3 次触达 SOP |
| 流失 | 低 | 低 | 低 | 不主动投入 |

## 运营资源分配公式

**重要挽留 + 流失 > 40% 时，本月全部资源投召回，不投拉新。**
挽留一个老客的成本 ≈ 拉新成本的 1/5，且老客客单高 30%+。

## 打标落地顺序（第一版只做这些）

1. 从订单表跑 RFM（一次性脚本，周更）
2. 渠道来源标签（接住就能分渠道复盘）
3. 品类偏好（最近 3 单主品类）
4. 其余标签等触达动作明确后再加
