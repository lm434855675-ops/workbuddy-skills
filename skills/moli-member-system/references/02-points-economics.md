# 02 积分经济学：发放、消耗、财务红线

## 三条铁律

1. **核销成本 ≤ 毛利的 20%**（脚本自动校验）——积分是延迟折扣，不是免费赠品
2. **积分有效期 12 个月滚动清零**——不过期的积分是财务负债，每年按「余额×核销率」计提
3. **消耗场景 ≥ 3 个**——只发不消耗 = 用户无感 + 负债堆积

## 发放场景（按 ROI 排序）

| 场景 | 发放 | 目的 |
|---|---|---|
| 消费 | 1 元 = 1 分 | 基础盘 |
| 完善资料 | 一次性 50 分 | 拿到标签数据 |
| 首购 | 一次性 100 分 | 拉第二单 |
| 评价带图 | 30 分 | UGC 素材 |
| 老带新 | 被邀双方各 200 分 | 裂变，成本可控 |

**禁止**：签到发积分（成本高、无行为价值）、关注公众号发积分（一次性动作无复购价值）。

## 消耗场景

| 场景 | 核销成本 | 说明 |
|---|---|---|
| 抵现（100 分=1 元） | 100% 面值 | 基础盘，设单笔抵扣上限（如 ≤10%） |
| 兑优惠券（500 分=20 元券） | 券有核销率，实际成本 = 面值×核销率 | 推荐主力，真实成本远低于抵现 |
| 兑实物/周边 | 采购价 | 低毛利商品别上 |
| 抽奖 | 期望值控制 | 大奖概率压到 0.5% 内 |

**主力放「兑券」**：20 元券核销率 40% = 真实成本 8 元，比 100 分抵 1 元（全额）省一半以上，还带来二次消费。

## 财务测算模型（脚本 points 命令）

```
月发放积分 = 月GMV × 每元发放分
月发放负债 = 发放积分 ÷ 积分面值（元）
月核销成本 = 负债 × 消耗率          ← 这才是当期真实成本
成本率 = 核销成本 ÷ 月GMV           ← 红线：≤ 毛利率 × 20%
未核销负债 = 负债 × (1-消耗率)       ← 资产负债表上的雷
```

## 防薅三件套

1. 单用户单日获取上限（如 500 分）
2. 退款订单同步扣回积分
3. 异常监控：单人月获取分值超同类目 P99 触发人工审核
