# 06 公私域联动：流量接得住，会员转得动

## 公域→私域承接路径（四段）

```
公域投放/平台自然流量
   ↓ ① 钩子：入会礼（首单券+积分），落地页只讲一件事「入会得什么」
加微/企微（个人号 or 企微）
   ↓ ② 30 秒 SOP：欢迎语=权益清单+1 个立刻能用的券
进群 or 打标
   ↓ ③ 7 天培育：D1 用券提醒 → D3 内容 → D5 社交证明 → D7 二单券
首单 → 打标 → 进会员体系
   ↓ ④ RFM 分层进入会员运营节奏
```

**钩子设计三原则**：成本 ≤ 客单毛利的 15%、即时兑现（不搞「满 1000 才送」）、与主业相关（餐饮送菜券，不是送洗碗机）。

## 入会钩子基准（按类目）

| 类目 | 钩子 | 成本控制 |
|---|---|---|
| 餐饮/烘焙 | 首单立减 + 免费甜品券 | ≤ 客单 20% |
| 零售/商城 | 入会礼包券（3 张分周发） | 券核销率核算 |
| 美业/服务 | 体验项目 1 次 | 边际成本低的服务 |
| 知识/教育 | 试听 + 资料包 | 零边际成本 |

## 触达节奏（30/60/90）

| 节点 | 动作 | 载体 |
|---|---|---|
| D0 | 欢迎语+权益清单+入会券 | 私聊自动 |
| D1 | 券到期提醒（48h 有效，制造紧迫） | 群发/企微 |
| D3 | 干货内容（品类相关） | 朋友圈+群 |
| D5 | 老客买家秀/社交证明 | 朋友圈 |
| D7 | 二单券（限时） | 私聊 |
| D30 | 首月复盘：满意度的 1 道题 + RFM 初标 | 问卷 |
| D60 | 未复购 → 唤醒券；已复购 → 升级引导 | 分层自动 |
| D90 | 会员体系正式权益全面生效 | 群发 |

## 公私域联动的三个常见死法

1. **钩子与主业无关**：送充电宝引来薅党，进来就屏蔽
2. **承接断档**：加了好友 3 天没人说话，窗口期（24h 内好感峰值）白白流走
3. **一次性群发轰炸**：D1-D7 七连发，用户直接删除。节奏是设计出来的，不是越多越好

## 度量口径（必须有，否则联动是玄学）

- 加微率 = 加微人数 ÷ 公域进店人数（行业基准 8-15%）
- 首单转化 = 30 天内首单 ÷ 加微人数（基准 20-35%）
- 入会率 = 入会 ÷ 加微（基准 50%+，钩子够硬可以到 70%）
- 90 天复购率 = 分层运营的核心 KPI
