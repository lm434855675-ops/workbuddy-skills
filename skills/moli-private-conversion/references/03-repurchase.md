# 03 · 复购与唤醒：分层唤醒策略

## 复购节奏表（按成交日排）

| 时点 | 动作 | 目的 |
|---|---|---|
| 成交后 D1 | 使用指导 + 服务确认 | 建立正确预期，降低退货 |
| D7 | 使用回访 | 解决问题+收集反馈素材（真实反馈才可用于内容） |
| D21 | 关联推荐 | 基于使用场景推荐，不群发 |
| D45 | 会员/复购权益告知 | 只对高价值客户 |
| D90 | 沉睡预警 | 超 90 天未复购转沉睡池 |

## 沉睡分层与唤醒

| 分层 | 判定 | 唤醒策略 |
|---|---|---|
| 浅沉睡（30-90 天） | 有互动无成交 | 内容触达+场景唤醒，不带促销 |
| 深沉睡（90-180 天） | 无互动无成交 | 大机制唤醒（专属回归礼），一触一静 |
| 流失（180 天+） | 多次触达无响应 | 归档；只在大型节点做最后触达 |

## 铁律

- 唤醒频次：浅沉睡每月 ≤2 次，深沉睡每季度 ≤1 次。超频 = 拉黑。
- 每次唤醒带一个**新信息**（新品/案例/权益变化），不是重复促销。
- 反馈素材必须真实：编造好评截图既违规又高危。

## 实证锚点（作者履历）

酵素项目：代理联盟商学院分层培训+终端动销方案设计；私护项目 20 人团队 1V1 跟进客户产品使用情况并收集反馈——**反馈收集本身就是复购与内容的共同基础设施**。
