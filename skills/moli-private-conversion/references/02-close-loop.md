# 02 · 成交链路：五级漏斗与各环节转化要点

## 五级漏斗（每日记录，优化只认这五个数）

```
进线 → 首响(≤5min) → 深聊(需求确认) → 成交 → 复购
```

| 环节 | 常见卡点 | 优化动作 |
|---|---|---|
| 进线 | 量不稳、质量差 | 归因到渠道与钩子，转公域专项 |
| 首响 | 超时、漏接 | 排班对齐流量波峰；自动回复只做"已收到+即将响应"，不做推销 |
| 深聊 | 问了价格就走、需求没挖出 | 需求确认三问：用给谁/解决什么/之前用过什么 |
| 成交 | 犹豫、比价、信任不足 | 分层举证（案例/背书/试用机制），不用统一逼单 |
| 复购 | 买完失联 | 复购节奏表（见 03） |

## 各环节转化要点

### 首响

- 黄金 5 分钟。首响话术三要素：确认身份（称呼）、确认来意（一句）、给预期（"我 2 分钟给您完整答复"）。
- 禁止首响即群发广告链接。

### 深聊（需求确认）

- 三问之后才介绍产品。顺序反了 = 自说自话。
- 记录三问答案到客户档案，分层依据。

### 成交

- 举证顺序：同品类案例 → 权威背书 → 低风险机制（试用/小单/退换）。
- 价格异议先问预算区间再给方案，不直接降价。
- 逼单只在需求确认+举证完成之后。

## 14 天成交 SOP 骨架（深聊后未成交的）

D1 深聊记录归档 → D3 案例补充 → D7 新信息触达（活动/新品/内容）→ D10 需求再确认 → D12 限时机制（真实的）→ D14 归档转沉睡池或成交。
每次触达必须带新信息，重复"在吗"是骚扰。

## 实证锚点（作者履历）

14 天成交转化 SOP：日进线 1500+ 的团队仍保持分层跟进，年度 GMV 1000 万。
核心不是话术多漂亮，是**漏斗五级每天有数、每周按数调整**。
