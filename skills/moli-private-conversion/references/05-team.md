# 05 · 团队与质检：排班、人效、抽检机制

## 排班原则

- 排班对齐流量波峰：先看进线量的时段分布，再排人，不要平均排班。
- 高峰时段（经验上 10-12 点、19-22 点）保证首响人力 ≥ 需求的 1.2 倍。
- 每人每日深聊量有上限（经验值 40-60 单），超限必掉转化率。

## 人效指标（每周看）

| 指标 | 口径 | 健康线（经验值，须自校准） |
|---|---|---|
| 人均日处理 | 处理单量 / 人数 | 40-75 |
| 首响达标率 | ≤5 分钟首响占比 | ≥90% |
| 深聊转化率 | 成交 / 深聊 | 15-30% |
| 质检合格率 | 抽检合格 / 抽检总数 | ≥85% |

## 质检抽检机制

- 每日抽检量：每人 ≥3 单（含 1 单成交 + 1 单未成交）。
- 抽检四看：首响时长、需求三问是否做了、话术合规、跟进记录是否归档。
- 质检结果三用：个人辅导、话术卡修订（共性问题进卡）、排班调整。

## 常见组织问题与处理

| 现象 | 根因 | 处理 |
|---|---|---|
| 新人转化率普遍低 | 培训不足 | 老带新 + 话术卡考核上岗 |
| 老人转化率下滑 | 话术疲劳/线索质量下降 | 先分因：分线测试 |
| 高峰漏接严重 | 排班错配 | 按流量波峰重排 |
| 质检合格率低但业绩好 | 话术踩合规红线 | 业绩让位合规，立即整改 |
