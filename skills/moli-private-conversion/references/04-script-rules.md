# 04 · 话术规范：结构模板 + 合规扫描规则

## 话术卡结构（每环节一张，四段）

1. **目标**：这张卡要拿到什么（回复？需求信息？成交？复购？）
2. **开场**：称呼+来意确认+给预期，三句话内。
3. **关键问答**：只列高频问题（价格/效果/售后/比价），每个问答一行。
4. **禁区**：本环节不能说的话。

## 常用话术框架

### 需求确认三问

```
1. 这个主要是您自己用，还是送人？（使用人）
2. 最想解决的是哪个问题？（痛点排序）
3. 之前用过类似的吗，感觉怎么样？（竞品经验/信任度）
```

### 价格异议处理

```
不先降价。顺序：问预算区间 → 给对应档位方案 → 讲清档位差异价值。
预算明显不匹配 → 推荐低门槛入门款，不硬推。
```

### 举证顺序

```
同品类真实案例 → 可查证背书 → 低风险机制（试用/小单/退换）
```

## 合规扫描规则（话术卡交付前必过）

| 类别 | 禁 | 替代表达 |
|---|---|---|
| 极限词 | 最/第一/100%/绝对/彻底 | 具体事实或删除 |
| 收益承诺 | 稳赚/保证回本/躺赚 | 删除；讲清投入产出逻辑不承诺结果 |
| 疗效宣称 | 治愈/根治/替代药物（健康类） | "个体体验，因人而异"+已核实的产品资料表述 |
| 紧迫感造假 | "最后 1 小时"（不真实时） | 真实截止时间 |
| 诱导 | "不买就没了"式恐吓 | 真实库存/权益说明 |

扫描输出：必改（原文→改法）/ 建议 / 通过。必改未清零不许交付。
