# 私域转化链路方案

帮你把"流量进来了接不住"这类诉求，转成**带承接话术、分层策略、跟进节奏与判定标准的可执行方案**。
本 skill 只管私域侧转化：**承接 → 分层 → 跟进 → 成交 → 复购**。不管公域投放怎么做。

## 第一步：判断场景

| 用户说什么 | 场景 | 读哪个文件 |
|---|---|---|
| 进线接不住 / 回复慢 / 客服跟不上 | 承接力诊断 | `@references/01-capacity.md` |
| 咨询不成交 / 问了就买别家 / 跟进没效果 | 成交链路 | `@references/02-close-loop.md` |
| 买完不复购 / 沉睡用户唤醒 | 复购与唤醒 | `@references/03-repurchase.md` |
| 话术怎么写 / 开场白 / 逼单 / 合规 | 话术规范 | `@references/04-script-rules.md` |
| 团队人效 / 排班 / 质检 | 团队与质检 | `@references/05-team.md` |
| **任何场景的最终交付** | **出 HTML 界面** | 深浅色自适应、可打印的自包含 HTML |

## 第二步：先要基线信息，缺了就问

必问（4 项）：

1. **日均进线量 + 承接人数** —— 决定承载力缺口多大
2. **客单价 + 毛利率** —— 决定话术力度与让利空间
3. **当前转化率**（咨询→成交）—— 没有就标「待补」，按行业默认 3-8% 假设继续
4. **成交周期**（几天内成交算正常） —— 决定跟进节奏设计

选问：历史分层数据、当前话术版本、企微/个微承接比例。
**最多问一轮，答不上来的标「待补」+默认假设，不要卡住。**

## 第三步：测算用脚本，不要口算

```bash
# 承接力测算：进线 vs 承接上限，缺口与增援方案
python3 scripts/conversion_calc.py capacity --daily-leads 1500 --staff 20 \
    --per-staff-hourly 8 --work-hours 8 --response-rate 0.7

# GMV 倒推：进线 × 响应率 × 承接深度 × 转化率 × 客单 × 复购系数
python3 scripts/conversion_calc.py gmv --daily-leads 1500 --response-rate 0.7 \
    --deep-rate 0.4 --close-rate 0.12 --aov 599 --repurchase 1.6

# 14 天跟进节奏排布
python3 scripts/conversion_calc.py rhythm --cycle 14 --touch-points 6 --key-days "1,3,7,10,12,14"
```

## 第四步：交付物

- **方案 HTML**：链路诊断 + 分层表 + 跟进节奏表 + 话术框架 + 排期（带 owner 与判定标准）。
- **话术卡**：每个环节一张（目标/开场/关键问答/禁区），话术必须过 `@references/04-script-rules.md` 合规扫描。
- **判定标准**：每个动作带"做到什么算完成"（响应时长、转化率、复购率数字）。

## 退出码处理

| 脚本 | 码 | 含义 | 处理 |
|---|---|---|---|
| conversion_calc.py | 0 | 成功 | 用输出数字 |
| | 1 | 参数错误 | 检查必填参数与比率格式 |
| | 2 | 测算无解 | 如 staff=0、响应率>1；修正后重跑 |

## 全局硬规则

| 项 | 要求 |
|---|---|
| 响应时效 | 首响 ≤5 分钟是及格线，超过 30 分钟的进线转化率断崖 |
| 分层先于群发 | 至少分高意向/观望/沉睡三档，同一套话术群发 = 把高意向用户推走 |
| 跟进有节奏 | 14 天成交周期内触达 5-7 次，每次带新信息，不重复问候 |
| 话术合规 | 禁极限词/收益承诺/疗效宣称；医疗健康类按品类红线处理 |
| 数据闭环 | 进线-响应-深聊-成交-复购五级漏斗必须每日记录，否则无法优化 |
| 不承诺结果 | 方案给方法与目标，不承诺具体成交数字 |

## 常见反模式：看到就纠正

- **"多招几个客服就行了"** → 先看首响时长与话术转化率，人效问题常是话术问题不是人数问题。
- **"把所有用户拉一个群"** → 大群触达效率低且干扰重；私域直营的核心是 1V1 分层承接。
- **"每天群发一次促销"** → 促销疲劳后打开率归零；触达节奏按 14 天 SOP 带信息增量。
- **"用户问了赶紧逼单"** → 逼单前置条件是信任与需求确认；未确认需求的逼单是赶客。
- **"先大量进线再优化承接"** → 承接不住的流量是净亏损：广告费花了，客服崩了，口碑差了。
- **"话术越全越好"** → 话术卡只保留高频关键问答，全量话术没人记得住。
