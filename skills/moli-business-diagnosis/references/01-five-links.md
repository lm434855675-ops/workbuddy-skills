# 01 · 五段链定义、检查项、评分锚点

## 五段链（串联，最上游断点优先修）

```
定位 → 价值 → 变现 → 增长 → 壁垒
```

## 定位

**检查项**：目标人群一句话说得清？不卖给谁说得清？价格带与人群匹配？

| 分 | 锚点 |
|---|---|
| 1-3 | "什么人都能买"；价格随缘 |
| 4-6 | 有人群但边界模糊；价格带与核心人群错位 |
| 7-8 | 窄人群清晰，定价权明确 |
| 9-10 | 定位即品类词，客户自动对号入座 |

## 价值

**检查项**：客户选你不选别家的理由？这个理由是客户感知得到的还是自嗨的？

| 分 | 锚点 |
|---|---|
| 1-3 | 只有"更便宜"或"更好" |
| 4-6 | 有差异点但客户感知弱 |
| 7-8 | 差异点客户可感知、可验证 |
| 9-10 | 价值主张自带传播性 |

## 变现

**检查项**：收钱路径几步？毛利撑不撑得住打法？复购结构？

| 分 | 锚点 |
|---|---|
| 1-3 | 路径长（>3 步）或毛利 <30% |
| 4-6 | 路径清晰但毛利结构单一 |
| 7-8 | 路径短、毛利健康、有复购设计 |
| 9-10 | 变现结构自带复购/裂变属性 |

## 增长

**检查项**：增量从哪来？可复制吗？依赖单一渠道/人脉？

| 分 | 锚点 |
|---|---|
| 1-3 | 增长全靠老板人脉或单一渠道 |
| 4-6 | 有 1-2 个渠道，不可复制 |
| 7-8 | 渠道可复制、有内容或机制杠杆 |
| 9-10 | 老带新占新增三成以上 |

## 壁垒

**检查项**：别人抄你需要多少成本？供应链/品牌/网络效应/数据？

| 分 | 锚点 |
|---|---|
| 1-3 | 无壁垒且利润可见（被抄倒计时） |
| 4-6 | 有弱壁垒（先发/区域） |
| 7-8 | 有供应链或品牌壁垒之一 |
| 9-10 | 多壁垒叠加或网络效应 |

## 打分纪律

每段打分必须附用户给出的事实依据；事实不足标「待补」按 5 分计并显式标注。禁止凭行业印象打分。
