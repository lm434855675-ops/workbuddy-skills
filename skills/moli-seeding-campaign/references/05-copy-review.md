# 05 · 文案与分镜规范 + 审校清单

## 笔记文案规范

| 项 | 要求 |
|---|---|
| 标题 | ≤20 字；带场景或结果；禁极限词；不用纯卖点罗列 |
| 正文 | 一篇只讲一个卖点；短句+分段；口语自然；600-900 字（图文） |
| 钩子 | 首句必须是痛点/场景/结果三选一，禁"今天给大家分享"式开头 |
| CTA | 一个动作：评论/收藏/进店/私信，四选一 |
| 标签 | 5-8 个，品类词+场景词+产品词，不堆热门无关标签 |

## 视频分镜规范（15-60 秒）

- 前 3 秒：钩子（痛点画面/结果画面/反常识一句）。
- 中段：一个卖点讲透，配使用画面。
- 结尾：CTA + 产品出现不超过 2 次。
- 字幕必须上（静音观看场景）。
- 分镜表格式：镜号 | 时长 | 画面 | 台词/字幕 | 备注。

## 发布前审校清单（逐条过，输出审校记录）

1. **极限词扫描**：最/第一/100%/绝了/封神/天花板… → 替换或删除。
2. **功效宣称**：护肤品禁治疗/医疗表述；养生食品禁疗效；普通食品禁功能声称。
3. **数据真实性**：所有使用效果描述有产品资料支撑，没有的标"个体体验，因人而异"。
4. **价格合规**：价格带规格与条件；划线价有真实成交依据。
5. **合作关系标注**：商业合作内容已按平台规则标注。
6. **竞品表述**：禁贬低、禁点名对比。
7. **诱导互动**：禁"不转不是""转发才能领"类表述。

审校结论三档：通过 / 必改（列原文→改法）/ 建议（提示用户决定）。必改未清零不许交付。
