# 06 · 投后复盘：指标口径与调整决策树

## 指标口径（复盘只认这几个数）

| 指标 | 口径 | 健康参考（经验值，须用自己历史校准） |
|---|---|---|
| CPE | 总花费 / 总互动量 | 越低越好，无绝对值标准 |
| 进店成本 | 总花费 / 进店人数 | 与店铺毛利对比 |
| 爆款率 | 互动超中位数 2 倍的笔记数 / 总笔记数 | 10-20% 属正常 |
| 搜索占位 | 核心词搜索结果前 20 中我方内容数 | 冷启动期核心指标 |
| 内容→成交 | 成交人数 / 进店人数 | 与店铺运营联动看 |

## 复盘决策树（效果不好时按序走）

```
整体不及预期？
├─ 到达问题？（曝光远低于预估）
│   ├─ 是 → 选题×层级错配：换选题或换达人，不加预算
│   └─ 否 → ↓
├─ 互动问题？（曝光够但互动低）
│   ├─ 是 → 钩子与卖点表达问题：重写前 3 秒/首句
│   └─ 否 → ↓
├─ 进店问题？（互动够但进店低）
│   ├─ 是 → CTA 与钩子产品化问题：换 CTA 形式
│   └─ 否 → ↓
└─ 成交问题？（进店够但成交低）
    └─ → 问题不在种草，在店铺/价格/私域承接，转对应专项
```

## 复盘产出（固定四件）

1. 数据表：各选题×各层级的 CPE/进店成本/爆款率。
2. 结论：下一轮保留哪几个选题、砍哪几个、测试哪几个新方向。
3. 假设变更记录：本轮哪些假设被证伪。
4. 达人复投名单：数据达标的达人进复投池（基于真实数据，不凭印象）。

## 红线

- 不复盘不开始下一轮：没有数据表的"下一轮加大投入"是赌博。
- 不用单篇爆款推全局，爆款率看分布不看个例。
