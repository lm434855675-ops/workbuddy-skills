# 04 · 文案合规：词库 + 结构规则

## 极限词库（必改）

精确命中（脚本直接判必改）：
顶级、绝对、100%、史上、独家、国家级、吊打、封神、绝了、无敌、销量冠军、领导者、极致、全网最低、最低价、最低、最便宜、最划算、最优质、最先进、最好、最好用、最佳、最优、最高、最高级、最大、最强、第一品牌、行业第一、销量第一、全国第一、排名第一

模糊表述（判建议改，需与事实核对）：
最后 N 小时、仅剩 N 件/份/席、限时 N 秒、抢完为止、手慢无

> 单字「最」「第一」不单独判：会误伤「最近 / 最后一个 / 第一时间」这类正常表述，一律用上表的组合词判定。上表与 `scripts/check_copy.py` 的 `ABSOLUTE` 逐词对应，改一处必须同步改另一处。

## 结构性合规（关键词改写救不了，必须改结构）

| 场景 | 结构要求 |
|---|---|
| 短信 | 【签名】开头；退订标识（"回 TD 退订"）；正文 ≤70 字；发送时段避开 21:00–08:00 |
| 裂变/分享 | 不得把分享/转发/关注设为领奖前置条件（微信诱导分享，链接会被拦截） |
| 自动续费/储值 | 必须明示扣费周期、扣费金额、取消路径；储值不得设置不合理使用期限 |
| 划线价 | 划线价须为真实成交过的价格，并留存举证（后台成交记录截图） |
| 多级分销 | 代理分润只讲"销售分润"，不讲"拉人头提成"；层级描述规避传销特征表述 |

## 平台红线（微信生态）

- 诱导分享：分享才可领奖/解锁 → 整场活动可能被拦截，直接换玩法。
- 诱导关注：关注才可下单 → 同上。
- 虚假活动：倒计时/名额与事实不符 → 投诉+封禁双重风险。

## 文案改写对照示例

| 原文 | 改法 |
|---|---|
| "全网最低价" | "本场会员专属价，日常售价 XX" |
| "100%有效" | "10 个人里 7 个回购"（有数据时）或删除 |
| "最后 1 小时" | 真实截止时间，且活动真实存在 |
| "邀请 3 人助力得券" | 换玩法：直接领券/会员日专属价 |

## 检查流程

`scripts/check_copy.py --scope <banner|sms|member|share|all> <文件>`，退出码 0/1/2 对应无命中/必改/建议改。
方案交付前，涉及文案的区块全部过一遍。
