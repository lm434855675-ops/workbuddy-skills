# 02 · 指标体系 + 埋点口径 + 取数节奏

## 核心指标口径

| 指标 | 口径 | 用途 |
|---|---|---|
| 坑位 UV 价值 | 引导 GMV / 曝光 UV | 楼层排序唯一依据 |
| 楼层 CTR | 点击 / 曝光 | 辅助判断素材问题，不用于排序 |
| 客单价 | 支付 GMV / 支付订单数 | 券门槛、保本测算输入 |
| 让利率 | 让利金额 / 成交 GMV | 必须 < 毛利率，脚本强校验 |
| 保本下单转化率 | 覆盖让利成本所需的最低转化 | mall_calc.py member 输出 |
| 增量 GMV | 活动 GMV − 平日日均 GMV × 活动天数 | 复盘唯一口径 |
| 触达成本 | 渠道花费 / 触达人数 | 触达顺序决策 |

## 埋点（活动前必须配好，事后补不了）

| 埋点 | 位置 | 用途 |
|---|---|---|
| 坑位曝光/点击 | 每个楼层、每个 Banner | 楼层诊断 |
| 渠道码 | 每条触达链接 | 归因到渠道 |
| 券领取/核销 | 券详情页、收银台 | 券效率 |
| 搜索词日志 | 搜索框 | 类目反哺 |

**命名规范**：`场景_元素_动作`，如 `home_floor01_click`、`memberday_sms_coupon_redeem`。
命名不统一的埋点，复盘时对不上账，等于没埋。

## 取数节奏

| 频率 | 取什么 | 干嘛用 |
|---|---|---|
| 每日 | GMV、订单、UV、转化率 | 盯异常 |
| 每周 | 楼层数据、券核销、渠道归因 | 周调整 |
| 每活动 | 漏斗五环节、增量 GMV、ROI | 复盘 |
| 每月 | 类目结构、搜索词、会员分层变化 | 结构性调整 |

## 复盘两棵诊断树

**GMV 掉了**：流量掉了？（渠道/坑位/自然）→ 转化掉了？（页面/价格/券/评价）→ 客单掉了？（货盘/凑单/连带）

**活动不及预期**：触达没到位？（到达率/打开率）→ 领了没用？（核销率/提醒）→ 用了不买？（门槛/面额/凑单）

**基准用自己**：所有对比基准用自己近 3 个月的中位数，不抄行业基准值——品类与私域结构差异太大。
